# Finnish Academy

An open-source, anime-styled Finnish language learning app built in a single self-contained HTML file. Learn both **Standard Finnish (*Kirjakieli*)** and **Spoken Finnish (*Puhekieli*)** with 120Hz-optimized animations, offline flashcards, a case builder, and a BYOK AI Tutor.

## Features
- **100% English UI:** Navigate effortlessly while learning proper and spoken Finnish.
- **Interactive Modules:** Pronunciation, Vowel Harmony, Core Cases, Everyday Finnish, and Verbs.
- **Spaced-Repetition Practice:** 42+ flashcards with normal (1.0x) and slow (0.7x) Finnish TTS, plus a timed Quick Blitz quiz.
- **Case Builder:** Visualize stem + suffix rules, vowel harmony, and K-P-T consonant gradation.
- **BYOK AI Tutor:** Bring your own API key (Google Gemini, OpenAI, Groq, OpenRouter, Claude, or Custom) for roleplay, Sentence X-Ray, and custom phrase generation. Keys are stored locally on your device only.
- **Backup & Restore:** One-tap `.json` export/import and `FA1:` Save Codes.

## Download Android APK
1. Go to the **Actions** tab in this repository.
2. Click the latest **Build Android APK** workflow run.
3. Download the **Finnish-Academy-APK** artifact, unzip it, and install `app-debug.apk` on your Android phone.

## Run Locally
Just open `www/index.html` in any modern browser, or enable **GitHub Pages** in repository settings to host it as a web app.
